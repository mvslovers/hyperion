LibTomMath for Hercules
=======================

This directory contains LibTomMath v1.3.0, the multiple-precision integer
library by Tom St Denis and the LibTom project:

    https://github.com/libtom/libtommath
    tag v1.3.0, commit 95d80fd8229d05dd6cb4ec88bc8d4f5377ff00ef

LibTomMath is released into the public domain (The LibTom license, see the
LICENSE file in this directory).

Contents:

    mpi.c               amalgamated library source, generated by
                        "make pre_gen" (pre_gen/mpi.c), unchanged
    tommath*.h          library headers, unchanged
    LICENSE             LibTomMath license

The files are NOT compiled on their own. dyncrypt_ecc.h includes mpi.c
exactly once into the dyncrypt module, configured with LTM_NOTHING and only
the functions needed for the elliptic curve support of the
Message-Security-Assist Extension 9 (KDSA, PCC scalar multiply). This way
no build system needs to know about these files.

To update LibTomMath: check out the new release tag, run "make pre_gen" and
copy pre_gen/mpi.c, tommath*.h and LICENSE into this directory.
